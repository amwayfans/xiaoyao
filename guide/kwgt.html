KWGT 訓練 Widget 設定指南

  • 目標裝置：vivo X100 Pro（OriginOS）
  • 資料源：https://amwayfans.github.io/xiaoyao/week.json（已上線，2026-10-27 驗證 HTTP 200）
  • 頭像：https://amwayfans.github.io/xiaoyao/images/xiaoyao-avatar-square-256.png
  • 設計規格：reports/SPEC-訓練Widget-2026-10-27.md

0. 前置

  1. 安裝 KWGT（Kustom Widget Maker，免費）
  2. 購買 KWGT Pro（約 NT$100–200）—— Flows、匯入、部分功能需要
  3. 確認版本 ≥ 3.77b435216（Android 15 有舊版停更 bug）

天數對照（重要，後面公式全靠它）

KWGT 的 df(E) 回傳 ISO 星期：1＝週一、2＝週二 … 7＝週日。

1. 建立 Widget

  1. 長按桌面空白處 → 「小工具」→ 找 KWGT → 選 4×3
  2. 放上桌面後點它 → 進入 KWGT 編輯器
  3. 右上角「預設」→ 新建 → 命名 訓練週表

2. 元素清單（依序加入）

座標是相對值（0–1），數值只是起點，之後拖曳微調。 每個「文字」元素的文字內容，把公式貼進 Text → 公式（計算機圖示） 欄位。

2-1 背景

  • 元素：形狀（Shape）
  • 尺寸：填滿整個 widget（W 1.00 / H 1.00）
  • 顏色：#12141A
  • 圓角（Corner）：20

2-2 頭像

  • 元素：圖片（Image）
  • 位置：X 0.03、Y 0.10、寬 0.16、高（自動等比）
  • 圖片來源 → 選 URL / Bitmap formula，貼：
https://amwayfans.github.io/xiaoyao/images/xiaoyao-avatar-square-256.png
  • 圓角：24（讓它與卡片一致）
  • 點擊動作：見 §4

2-3 標題「本週訓練」

  • 元素：文字
  • 位置：X 0.22、Y 0.10
  • 字級：15
  • 顏色：#E8EAED
  • 內容：本週訓練

2-4 週次（右上）

  • 元素：文字
  • 位置：X 0.72、Y 0.10
  • 字級：13
  • 顏色：#8A8F98
  • 內容（取 2026-W44 的後 3 碼 → W44）：
$tc(reg, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .week), ".*-", "")$

2-5 星期列（7 個小字）

  • 元素：文字 ×7
  • Y 統一 0.40、字級 12、顏色 #8A8F98
  • X 位置：0.06 / 0.19 / 0.32 / 0.45 / 0.58 / 0.71 / 0.84
  • 內容：一 二 三 四 五 六 日

2-6 訓練列（7 個，會變色）

  • 元素：文字 ×7
  • Y 統一 0.52、字級 14、粗體
  • X 位置同上
  • ★ 顏色用公式（今天紫色、訓練日白色、休息日暗灰）：

週一那格：

$if(df(E)=1, "#7C3AED", if(wg("https://amwayfans.github.io/xiaoyao/week.json", json, .mon)="休息", "#4A4F58", "#E8EAED"))$

週二那格（把 df(E)=1 改成 df(E)=2、.mon 改成 .tue）：

$if(df(E)=2, "#7C3AED", if(wg("https://amwayfans.github.io/xiaoyao/week.json", json, .tue)="休息", "#4A4F58", "#E8EAED"))$

依此類推：週三 df(E)=3 + .wed、週四 df(E)=4 + .thu、週五 df(E)=5 + .fri、週六 df(E)=6 + .sat、週日 df(E)=7 + .sun

  • ★ 文字內容（顯示「胸」就夠，太長會擠）：用 tc(reg) 截短

週二那格內容：

$tc(reg, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .tue), "＋.*", "")$

（胸＋三頭 → 胸；休息 保持 休息；背＋肩 → 背）

2-7 今日大字（底部）

  • 元素：文字
  • 位置：X 0.06、Y 0.76
  • 字級：18、粗體、顏色 #E8EAED
  • 內容：
今天 · $if(df(E)=1, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .mon), if(df(E)=2, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .tue), if(df(E)=3, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .wed), if(df(E)=4, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .thu), if(df(E)=5, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .fri), if(df(E)=6, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .sat), wg("https://amwayfans.github.io/xiaoyao/week.json", json, .sun)))))))$

2-8 更新狀態（極小字，右下）

  • 元素：文字
  • 位置：X 0.72、Y 0.88
  • 字級：9、顏色 #4A4F58
  • 內容（顯示資料時間的日期）：
$df("MM/dd", tc(reg, wg("https://amwayfans.github.io/xiaoyao/week.json", json, .updated), "T.*", ""))$

3. 刷新設定（關鍵）

KWGT 編輯器 → 右上「設定」→ 更新模式：

  • 選 自動
  • 間隔：60 分鐘
  • 勾選「允許通知」（背景更新必要）

資料一天只變一次，60 分鐘足夠。想更省電可設 180 分鐘，跨日時 Widget 會晚一點切換。

4. 點擊動作

4-1 頭像 → 開 Telegram

  1. 選中頭像 → 觸控（Touch）
  2. 動作類型：開啟連結
  3. URL：https://t.me/（或你自己的 Telegram 使用者名稱連結，例如 https://t.me/你的帳號）

4-2 每一天的格子 → 開該日處方

需要 7 個透明矩形蓋在每天的格子上（W 0.12 / H 0.18，填色透明度 0）：

以週二為例：

  1. 加一個形狀，顏色透明（Alpha 0）
  2. 位置對齊週二那一欄
  3. 觸控 → 開啟連結 → URL 填公式：
$wg("https://amwayfans.github.io/xiaoyao/week.json", json, .tue_url)$

其餘六天把 .tue_url 換成 .mon_url / .wed_url / .thu_url / .fri_url / .sat_url / .sun_url

4-3 其餘空白處

不設動作（避免誤觸）。

5. vivo X100 Pro 必做四步

OriginOS 會殺背景，四步缺一不可：

  1. 設定 → 電池 → 背景耗電管理 → KWGT → 允許背景高耗電
  2. 設定 → 應用程式 → 應用程式管理 → KWGT → 權限 → 自啟動（開）
  3. 開最近任務 → 長按 KWGT 卡片 → 鎖定（出現鎖頭）
  4. KWGT 內 → 設定 → 更新模式「自動」＋ 允許通知

若仍停更：KWGT → 設定 → 強制刷新；再不行就重裝最新版。

7. 已知限制

  1. 每次刷新會打一次網路（657 bytes），斷網時顯示上一次的結果
  2. 臨時改期要告訴小妖改計畫檔，隔天 00:05 自動反映；當天改需手動觸發 gen_widget.py 再 push
  3. KWGT 免費版限制部分功能，Flows 與匯入需 Pro

8. 疑難排解

症狀 處理
顯示空白或 undefined 檢查 URL 能否在手機瀏覽器打開 week.json
資料停在舊的 關閉電池優化、鎖定背景（§5）
中文沒顯示 元素字型改用系統字型，或設 Noto Sans TC
頭像不顯示 用瀏覽器開圖片 URL 確認；KWGT 圖片公式不要加引號
今天高亮錯位 確認用 df(E)（ISO 1=週一），不是 df(u)
